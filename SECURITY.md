# Sicurezza

## Segnalare una vulnerabilità

Se trovi un problema di sicurezza su robertodisanto.it, scrivi a info@robertodisanto.it. Per favore non aprire issue pubbliche e lasciami il tempo di sistemarlo prima di parlarne.

Lo stesso contatto è in [/.well-known/security.txt](https://robertodisanto.it/.well-known/security.txt).

## Vecchie app iOS nella history

La vecchia history di questo repo è ancora raggiungibile tramite alcuni riferimenti git. Contiene build iOS di test, cioè file `.ipa`, del periodo 2017–2019. Non installarle, non ri-firmarle e non usarle.

- **Sono inerti.** Le build sono firmate con profili di sviluppo scaduti tra il 2018 e il 2019, validi solo sui dispositivi di test di allora. Le build chiamate "YouTube" non hanno nessun profilo. Un iPhone normale non le installa.
- **Alcune erano demo didattiche.** Le build "YouTube" imitavano l'app ufficiale per mostrare il furto di credenziali in una lezione di network security. Non sono app pubblicate e non vanno riusate fuori da una lezione.
- **Le altre sono build di test** di progetti open source e di esercitazioni, non distribuzioni ufficiali.

## English

Please report security issues to info@robertodisanto.it rather than in public issues.

The old history of this repository still contains iOS test builds (`.ipa`, 2017–2019). Do not install, re-sign or use them. Their development profiles expired in 2018–2019, and the "YouTube" builds carry no profile at all. Those were a credential-theft demo for a network security class.
